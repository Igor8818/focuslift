## 🏆 Projeto Destaque: [FocusLift](https://github.com/Igor8818/focuslift)

> **Plataforma Full-Stack de Alta Performance para Musculação & Sobrecarga Progressiva**  
> *Mobile Offline-First + Cloud REST API em Java 21, Spring Boot 3, PostgreSQL e Docker.*

### 🔍 Destaques de Engenharia do FocusLift:
- **Backend Corporativo em Java 21 & Spring Boot 3.4:** API RESTful stateless protegida por **Spring Security 6 e tokens JWT**, com senhas criptografadas em **BCrypt**.
- **Sincronização Idempotente com Tombstones:** Protocolo bidirecional que reconcilia alterações offline do SQLite com a nuvem PostgreSQL, com resolução de conflitos e exclusões lógicas seguras.
- **AI Coach Anti-Alucinação:** Integração com **Google Gemini 2.5 Flash** aliada a um motor matemático determinístico no backend (`ProgressionMathEngine.java`), calculando 1RM (fórmula de Brzycki), volume semanal e platôs de carga antes de injetar no LLM.
- **Flyway Migrations & Índices:** Controle de versão de esquema relacional no PostgreSQL com índices otimizados para alta concorrência.
- **Docker Multi-Stage:** Build otimizado em Alpine Linux com execução mínima em JRE 21 headless.
- **Mobile Offline-First:** Experiência com zero latência no app (React Native + Expo) via SQLite local e consultas parametrizadas.
